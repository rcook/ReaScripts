# Category: ChordTrack

Entrypoints:

* `rcook_ChordTrack_AddChords.lua`: Add media items to a given chord track labelled with chord names
* `rcook_ChordTrack_DumpChords.lua`: Dump chord names corresponding to media items in the default chord track (debugging)
* `rcook_ChordTrack_RenderChords.lua`: Render chord names in given chord track as a MIDI media item in the given MIDI track
